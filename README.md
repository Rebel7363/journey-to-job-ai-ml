# Journey to Job: AI / ML Engineering Track

Repository documenting foundational to advanced implementations in Python, Data Engineering, and Machine Learning.

## 01. Python Basics (`01_Python_Basics/`)
- `01_modules_and_pip.py`: Built-in modules, external package imports via pip, and OS subprocess automation.
- `02_variables_datatypes.py`: Dynamic typing, memory references, and explicit type casting.
- `03_operators_and_input.py`: User input handling, arithmetic/logical operations, and identity vs value checks.
- `04_strings_and_slicing.py`: Slicing with step syntax, immutability constraints, and text preprocessing.

## Environment
- Python 3.14+ (macOS Virtual Environment `.venv`)
- Version Control: Git / GitHub Desktop
