# Journey to Job: AI / ML Engineering Track

Repository documenting foundational to advanced implementations in Python, Data Engineering, and Machine Learning.

## 01. Python Basics (`01_Python_Basics/`)

- `01_modules_and_pip.py`: Built-in modules, external package imports via pip, and OS subprocess automation.
- `02_variables_datatypes.py`: Dynamic typing, memory references, and explicit type casting.
- `03_operators_and_input.py`: User input handling, arithmetic/logical operations, and identity vs value checks.
- `04_strings_and_slicing.py`: Slicing with step syntax, immutability constraints, and text preprocessing.
- `05_conditional_logic.py`: Branching logic, ternary expressions, short-circuiting, and structural pattern matching.
- `06_loops_and_iteration.py`: Iteration protocols, enumerate, zip, loop control mechanics, and list comprehensions.
- `07_functions_and_scope.py`: Type hints, *args / **kwargs, unpacking, lambdas, and LEGB variable scope.

## 02. Data Structures (`02_Data_Structures/`)

- `01_lists_and_tuples.py`: CPython dynamic array resizing, overallocation mechanics, memory footprint profiling, and copy semantics.
- `02_dictionaries_and_sets.py`: Hash table bucket mapping, compact dict architecture, O(1) vs O(n) lookup benchmarks, and NLP Jaccard similarity.
- `03_stacks_and_queues.py`: LIFO stack with syntax validation, collections.deque block architecture vs list shift overhead, and monotonic stack patterns.
- `04_linked_lists.py`: Singly and doubly linked lists, O(1) auxiliary space in-place pointer reversal, and Floyd's cycle detection algorithm.
- `05_trees_and_graphs.py`: Binary Search Tree invariants and in-order traversals, alongside adjacency-list Graph Breadth-First (BFS) and Depth-First Search (DFS).
